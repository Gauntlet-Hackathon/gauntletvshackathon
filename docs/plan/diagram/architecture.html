Offline rescue triage: field + cloud architecture

SLM reads, Mercury decides. Field laptops work offline and sync to the cloud through an outbox. Kafka is the cloud's only source of truth. The cloud UI shows the live fleet, records and model evals. A hosted field instance lets judges try the laptop side live. Models are trained outside this system and pulled from Hugging Face; one ships to laptops only if it passes the eval gate.
